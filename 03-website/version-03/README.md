# IRONKIN website, version 03 (The Kin Society)

Identity v7: dark streetwear community. The hero is the anvil set in ~900 live rhinestones that scatter from the cursor and re-set themselves, under the chrome IRONKIN arch. Then the drop rail (3 Kin Society tees + Collection 001), the Kin Society (crest + tilting Kin card), the members wall and The Yard (redacted coordinates, countdown, dog-tag sign-up).

Built with Vite + React, Tailwind v4 + shadcn/ui, GSAP ScrollTrigger, Lenis, anime.js, Motion and React Bits (`src/bits/`, MIT + Commons Clause).

## Run it

Double-click `../start-version-03.bat` (installs once, opens http://localhost:5183), or `npm install` then `npm run dev -- --port 5183`.

Hold-my-size and the Kin sign-up are front-end only; prices are not set; The Yard coordinates are a placeholder; photos are AI stand-ins.
